# jeffreyjczy.github.io

Static portfolio for university projects, designed for GitHub Pages.

Public site: https://jeffreyjczy.github.io/

## Add a New Project

1. Add the built project folder to the repository.
2. Add an entry to `projects.json` with a unique `slug`, title, summary, category, and `path`.
3. Refresh the portfolio. The project list and route are generated automatically.

Project detail routes use hash URLs such as `#/projects/react-mygpa`, so they work on static hosting without server routing.
